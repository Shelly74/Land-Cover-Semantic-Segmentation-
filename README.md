## Land Cover Semantic Segmentation Pytorch | Python , Machine Learning and Deep Learning , Gen AI

An end-to-end Promptable Semantic Segmentation computer vision application built with PyTorch, Python, and AutoML configurations to analyze and classify geospatial satellite imagery. Powered by deep learning pipelines and generative AI promptable concepts, this project leverages the LandCover.ai Data dataset to perform automated land use and land cover (LULC) classification.
